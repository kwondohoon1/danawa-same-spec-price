# 동일스펙 가격비교

다나와 최저가를 기준으로 그래픽카드 · SSD · RAM의 **동일스펙 가격표**를 보여주는 GitHub Pages 사이트입니다.
단가표 엑셀을 올리면 자사 모델의 **노출가(2차혜택가)** 와 동일스펙 최저가의 차이를 계산합니다.

## 데이터

- 가격·스펙: [danawa-monitor-crawler](https://github.com/kwondohoon1/danawa-monitor-crawler)의 `data/latest/*.csv`, `data/specs/*_specs.csv`를 페이지를 열 때마다 실시간으로 불러옵니다.
- 중고 · 해외구매 · 리퍼 · 벌크 상품은 제외합니다.
- 상품명에 `한성컴퓨터`가 붙은 다나와 상품은 자사 상품으로 보고 경쟁 최저가 계산에서 뺍니다.

## 동일스펙 기준

기본 스펙이 같은 상품 중에서, 자사 제품과 **같거나 더 좋은 스펙**만 경쟁 상품으로 봅니다.

| 카테고리 | 기본 스펙 | 추가 조건 |
|---|---|---|
| 그래픽카드 | 칩셋 + 메모리 용량 | 팬 개수 이상 · 자사가 LED면 LED |
| SSD | 폼팩터 + PCIe 세대 + 용량 | TLC 이상(QLC 제외) · 자사가 DRAM이면 DRAM · 순차 읽기/쓰기(천 단위 내림) 이상 · 보증기간 이상 |
| RAM | DDR 세대 + 클럭 + 총 용량 + 모듈 개수 | CL 같거나 낮음 · 자사가 RGB면 RGB |

- 엑셀에 있는 자사 모델의 다나와 상품끼리는 서로 경쟁에서 제외합니다.
- 삼성처럼 여러 판매처가 같은 상품을 파는 브랜드는, 같은 상품이 자사 노출가보다 싸면 경쟁에 포함합니다.

## 엑셀 비교

1. 사이트에서 단가표 엑셀(`.xlsx`)을 끌어놓거나 선택합니다.
2. `모델명`, `카테고리`, `노출가 (2차혜택가)`, `원가` 열이 있는 시트(기본: `정산가세팅`)와 G마켓 `마켓 조건`을 읽습니다.
3. 모델별로 엑셀 노출가, 다나와 노출가(자사 상품), 동일스펙 최저가, 차이, 순위를 보여줍니다. 상품명을 누르면 다나와로 이동합니다.
4. **제안 노출가** = 동일스펙 최저가 × 99% (10원 단위 내림). 이미 −0.5~−1% 안이면 유지합니다.
   제안가로 G마켓 정산 시 원가보다 낮아지면 `손실·보류`로 두고 현재가를 유지하며 손익분기 노출가를 보여줍니다.
5. `제안 노출가 복사`를 누르면 엑셀 행 순서대로 한 줄에 하나씩 복사됩니다. `정산가세팅` 입력가(E18)에 그대로 붙여넣으면 됩니다.

엑셀은 브라우저 안에서만 읽습니다. 서버로 전송하거나 저장하지 않으며, 새로고침하면 사라집니다.

> ⚠️ 내부 단가표 엑셀은 이 저장소에 올리지 않습니다. `.gitignore`에 `*.xlsx`, `*.xls`, `*.xlsm`, `*.csv`가 등록되어 있습니다.
