# 동일스펙 가격비교

다나와 최저가를 기준으로 그래픽카드 · SSD · RAM의 **동일스펙 가격표**를 보여주는 GitHub Pages 사이트입니다.
단가표 엑셀을 올리면 자사 모델의 **노출가(2차혜택가)** 와 동일스펙 최저가의 차이를 계산합니다.

## 데이터

- 가격·스펙: [danawa-monitor-crawler](https://github.com/kwondohoon1/danawa-monitor-crawler)의 `data/latest/*.csv`, `data/specs/*_specs.csv`를 페이지를 열 때마다 실시간으로 불러옵니다.
- 중고 · 해외구매 · 리퍼 · 벌크 상품은 제외합니다.
- 상품명에 `한성컴퓨터`가 붙은 다나와 상품은 자사 상품으로 보고 경쟁 최저가 계산에서 뺍니다.

## 동일스펙 기준

| 카테고리 | 같은 스펙으로 보는 조건 |
|---|---|
| 그래픽카드 | 칩셋 + 메모리 용량 (예: RTX 5070 Ti · 16GB) |
| SSD | 폼팩터 + PCIe 세대 + 용량 (예: M.2 · PCIe5.0 · 2TB) |
| RAM | DDR 세대 + 클럭 + 총 용량 + 모듈 개수 (예: DDR5-6400 · 32GB (2개)) |

## 엑셀 비교

1. 사이트에서 단가표 엑셀(`.xlsx`)을 끌어놓거나 선택합니다.
2. `모델명`, `카테고리`, `노출가 (2차혜택가)` 열이 있는 시트(기본: `정산가세팅`)를 찾아 읽습니다.
3. 모델별로 동일스펙 최저가, 차이, 차이율, 순위를 보여줍니다. `보기`를 누르면 동일스펙 상품 전체 목록이 나옵니다.

엑셀은 브라우저 안에서만 읽습니다. 서버로 전송하거나 저장하지 않으며, 새로고침하면 사라집니다.

> ⚠️ 내부 단가표 엑셀은 이 저장소에 올리지 않습니다. `.gitignore`에 `*.xlsx`, `*.xls`, `*.xlsm`, `*.csv`가 등록되어 있습니다.
